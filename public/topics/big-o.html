Как я рассуждаю

Сначала называю n. Здесь n — количество чисел. Потом считаю, сколько раз выполнится строка внутри цикла. Если на каждое число приходится одна проверка, при удвоении списка число проверок тоже удвоится.

Разбор по шагам

Посчитай, сколько чётных чисел в списке [4, 7, 2, 9].

Python 3
def count_even(nums):
    count = 0
    for x in nums:
        if x % 2 == 0:
            count += 1
    return count

print(count_even([4, 7, 2, 9]))

Сложность и границы

O(n) времени и O(1) дополнительной памяти. Проверок ровно n, даже если все числа нечётные. Два таких прохода подряд дают 2n проверок, то есть всё ещё O(n).

Границы и частые ошибки

Вложенный цикл требует отдельного подсчёта. Если для каждого из n чисел второй цикл перебирает все n чисел, получаем n × n проверок и O(n²).

Самостоятельная практика

Напиши count_above(nums, limit). Верни количество чисел строго больше limit за один проход.

Примеры для проверки

count_above([3, 5, 7, 5], 5) → 1; count_above([], 5) → 0.

Ещё одна задача

Если в списке 6 нечётных чисел, сколько раз проверится условие и что вернёт функция?

Подсказка

Отдельно посчитай входы в if и случаи, когда условие истинно.

Сверить ответ

6 проверок, ответ 0. Цикл посетит каждый элемент, счётчик ни разу не увеличится.
