Индексы и границы

Даны позиции или нужно обработать только часть списка.

Как я рассуждаю

Подписываю индексы над числами, начиная с нуля. Для участка [left, right) стартую в left и останавливаюсь перед right. Длина участка равна right − left.

Разбор по шагам

В списке [8, 5, 2, 9] найди сумму чисел с индекса 1 до индекса 3, правую границу исключи.

inums[i]Сумма
155
227

Решение на Python

Python 3
def range_total(nums, left, right):
    total = 0
    for i in range(left, right):
        total += nums[i]
    return total

print(range_total([8, 5, 2, 9], 1, 3))

Вывод программы

7

Сложность и границы

Время O(right − left), память O(1). Срез списка потребовал бы дополнительной памяти на копию.

Предполагаем 0 ≤ left ≤ right ≤ len(nums). Если left == right, участок пуст. Правая граница может совпадать с len(nums), потому что цикл до неё не доходит.

Проверь себя

Какой диапазон передать, чтобы взять только последнее число из списка длины 4?

Подсказка

У последнего элемента индекс 3.

Сверить ответ

[3, 4). Цикл выполнится один раз при i = 3.

Теперь напиши сам

Напиши count_zero(nums, left, right). Посчитай нули только на участке [left, right).

Примеры для проверки

count_zero([0, 3, 0, 0], 1, 3) → 1; count_zero([0], 0, 0) → 0.
