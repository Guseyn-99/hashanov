Словарь и частоты

Нужно помнить дополнительную информацию о числе. Например, сколько раз оно уже встретилось.

Как я рассуждаю

Число беру как ключ, количество — как значение. Если ключ новый, начинаю с нуля. При каждом появлении увеличиваю его счётчик на один.

Разбор по шагам

Посчитай, сколько раз каждое число встречается в списке [4, 7, 4, 4].

Python 3
nums = [4, 7, 4, 4]
counts = {}
for x in nums:
    counts[x] = counts.get(x, 0) + 1
print(counts)

Сложность и границы

Для целочисленных ключей получение и запись в среднем занимают O(1). Проход занимает O(n) в среднем. В словаре k записей по количеству разных чисел, память O(k).

counts[x] += 1 для нового ключа вызовет KeyError. Вызов get(x, 0) даёт стартовое значение; запись появляется при присваивании counts[x] = … .

Самостоятельная практика

Напиши first_single(nums). Верни первое число, которое встретилось ровно один раз. Если такого числа нет, верни None.

Примеры для проверки

first_single([4, 7, 4, 2]) → 7; first_single([3, 3]) → None. Подсказка: сначала собери частоты, затем пройди по исходному списку.

Ещё одна задача

Как изменится словарь после ещё одной семёрки? Изменится ли len(counts)?

Подсказка

Длина словаря равна числу разных ключей.

Сверить ответ

{4: 3, 7: 2}. Длина останется равной 2, потому что ключ 7 уже был.

Проверь себя

1. Что вернёт {}.get(7, 0)?

2. В словаре {4: 3, 7: 1} увеличили счётчик числа 4. Сколько ключей теперь?
