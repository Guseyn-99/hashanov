Как я рассуждаю

Первое окно считаю целиком. Потом сдвигаюсь на один шаг. Одно число ушло слева, одно пришло справа. Вычитаю ушедшее и прибавляю пришедшее.

Разбор по шагам

За пять дней решено [2, 5, 1, 6, 3] задач. Сколько максимум удалось решить за три дня подряд?

Python 3
def best_sum(nums, k):
    if not 1 <= k <= len(nums):
        return None
    current = sum(nums[i] for i in range(k))
    best = current
    for right in range(k, len(nums)):
        current -= nums[right - k]
        current += nums[right]
        best = max(best, current)
    return best

print(best_sum([2, 5, 1, 6, 3], 3))

Сложность и границы

O(n) времени и O(1) дополнительной памяти. На сдвиг тратим две арифметические операции. Если заново суммировать каждое окно, потребуется до O(nk) времени.

Границы и частые ошибки

best начинаем с суммы первого окна. При отрицательных числах ноль может оказаться больше любой настоящей суммы. Для неподходящего k функция возвращает None.

Самостоятельная практика

Напиши worst_sum(nums, k). Найди наименьшую сумму среди окон длины k. Для недопустимого k верни None.

Примеры для проверки

worst_sum([3, 1, 5, 2], 2) → 4; worst_sum([-4, -2], 1) → -4; worst_sum([], 1) → None.

Подсказка
