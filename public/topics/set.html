Вопрос к каждому числу один: встречал ли я его раньше?

Как я рассуждаю

В seen отмечаю всё, что уже встречал. В result складываю числа в нужном порядке. Сначала проверяю число, потом добавляю его. Множество отвечает за проверку, список — за порядок.

Разбор по шагам

Убери повторы из [1, 3, 1, 5, 3, 7], сохранив первые появления.

Python 3
nums = [1, 3, 1, 5, 3, 7]
seen = set()
result = []
for x in nums:
    if x not in seen:
        seen.add(x)
        result.append(x)
print(result)

Сложность и границы

Проверка и добавление в множество в среднем занимают O(1). Весь проход — O(n) в среднем, память — O(k), где k — число разных элементов.

Пустое множество создаётся как set(). Запись {} создаёт словарь. При обходе set порядок первых появлений не гарантируется.

Самостоятельная практика

Напиши first_repeat(nums). Верни первое число, которое встретилось во второй раз. Если повторов нет, верни None.

Примеры для проверки

first_repeat([4, 7, 7, 4]) → 7; first_repeat([0, 1, 0]) → 0; first_repeat([]) → None.
