Префиксные суммы

Список остаётся одним и тем же, но просят суммы на разных участках.

Как я рассуждаю

Записываю, сколько накопилось до каждой границы. prefix[0] = 0, потому что до начала списка ничего нет. Чтобы получить сумму [left, right), из накопленного до right вычитаю всё, что было до left.

Разбор по шагам

Даны [3, 1, 4, 2]. Найди суммы на участках [1, 3) и [0, 4).

Граница iСколько чисел учлиprefix[i]

Решение на Python

Python 3
nums = [3, 1, 4, 2]
prefix = [0]
for x in nums:
    prefix.append(prefix[-1] + x)

for left, right in [(1, 3), (0, 4)]:
    print(prefix[right] - prefix[left])

Вывод программы

5
10

Сложность и границы

Построение занимает O(n) времени и O(n) памяти. Один запрос — O(1), все q запросов вместе с построением — O(n + q). Для первого запроса: 8 − 3 = 5.

Если правая граница включена в условии, для неё нужен prefix[right + 1]. При изменении числа в исходном списке соответствующие префиксы придётся обновить.

Проверь себя

Для тех же чисел что дадут участки [2, 4) и [2, 2)?

Подсказка

Во втором запросе обе границы одинаковы.

Сверить ответ

6 и 0. Для первого участка 10 − 4 = 6, для пустого участка 4 − 4 = 0.

Теперь напиши сам

Напиши range_sums(nums, queries). Для каждого запроса (left, right) верни сумму [left, right). Построй префиксы один раз.

Примеры для проверки

range_sums([2, -3, 4], [(0, 3), (1, 3), (1, 1)]) → [3, 1, 0].
