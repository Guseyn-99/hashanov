## 🧩 Что внутри каждой темы

- **Идея решения.** Как распознать задачу и с чего начать.
- **Пошаговый разбор.** Подсветка строки Python, значения переменных и пояснение к каждому шагу.
- **Сложность и границы.** Сколько времени и памяти нужно алгоритму и где легко ошибиться.
- **Практика.** Задача для самостоятельного решения и два вопроса с вариантами ответа.
