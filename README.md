# Hashanov

Личный справочник Гусейна Гасанова по алгоритмам на Python. Готовые страницы лежат в public.

## Открыть на компьютере

Открой public/index.html в браузере. Для локального веб-сервера выполни из корня проекта:

    py -m http.server 8000 --directory public

Адрес локального сайта — http://localhost:8000.

## Опубликовать на Vercel

Загрузи содержимое этой папки в свой репозиторий GitHub. В Vercel выбери Add New → Project и импортируй репозиторий. В качестве корня выбери папку с vercel.json. Настройки проекта уже заданы в vercel.json. Готовые HTML-страницы берутся из public. Нажми Deploy.

Если используешь Vercel CLI, из папки с vercel.json выполни:

    npx vercel --prod

После подключения репозитория Vercel публикует изменения при отправке в production-ветку.

## Добавить или исправить конспект

1. Открой lessons.py. Каждый элемент списка lessons задаёт одну тему. В trace записаны шаги ручного прогона. В drills под тем же slug лежит самостоятельное задание.
2. Выполни из корня проекта команду py build.py в Windows или python3 build.py в Linux/macOS.
3. Открой public/index.html. Проверь новую карточку и страницу. Отправь в GitHub изменённые исходники и обновлённую папку public.

Материалы опираются на практику курса ОП.04. В каждом конспекте есть ссылка на соответствующий раздел преподавателя.
